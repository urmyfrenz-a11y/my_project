# 서울 상권분석 서비스 — API 키 발급 가이드

이 프로젝트는 **9개 분석 팩터**를 3개의 키만으로 커버합니다.
포털 계정 1개당 인증키 1개가 산하 모든 API에 공통 적용되기 때문입니다.

## 발급받을 키 (총 3개)

| # | 키 | 발급처 | 커버 팩터 | 프론트 노출 |
|---|-----|--------|-----------|:---:|
| 1 | 카카오 **JavaScript 키** | developers.kakao.com | 지도 표시 | ✅ (도메인 제한) |
| 1 | 카카오 **REST API 키** | developers.kakao.com | 주소검색·좌표변환·POI(9번) | ❌ 서버 전용 |
| 2 | 서울 열린데이터광장 **인증키** | data.seoul.go.kr | 2·3·4·5·6번 | ❌ 서버 전용 |
| 3 | 공공데이터포털 **serviceKey** | data.go.kr | 1·7·8·9번 | ❌ 서버 전용 |

> 핵심: **서울(②)·공공데이터(③)는 계정당 키 1개**로 산하 API 전부 호출.
> API별 "활용신청"만 개별로 누르면 되고, 인증키를 여러 번 받을 필요 없음.

---

## ① 카카오 (developers.kakao.com)

1. 로그인 → **내 애플리케이션 → 애플리케이션 추가하기**
2. 앱 1개 생성 시 **JavaScript 키 / REST API 키**가 동시에 발급됨
3. **앱 설정 → 플랫폼 → Web** 에 도메인 등록 (`http://localhost:3000`, 실배포 도메인)
4. **카카오맵** 제품 ON
- JavaScript 키 → 지도 렌더링 (클라이언트)
- REST API 키 → 카카오 로컬 API(주소검색, 좌표변환, 키워드/카테고리 장소검색 = 9번 POI)

## ② 서울 열린데이터광장 (data.seoul.go.kr)

1. 회원가입/로그인 → **마이페이지 → 인증키 신청/관리** → 일반 인증키 발급 (1회)
2. 이 키 하나로 상권분석서비스 데이터셋 전부 호출:
   - 길단위인구·생활인구(2) / 상주·직장인구(3) / 소득소비(4) / 추정매출(5) / 점포·상권변화지표(6)
3. 즉시 발급. 1회 최대 1,000건 → 페이징 처리 필요.

## ③ 공공데이터포털 (data.go.kr)

각 데이터에서 **활용신청** 클릭 (대개 즉시~2시간 승인), 인증키(Decoding)는 공통:
- 소상공인시장진흥공단_상가(상권)정보 → 1번  (data 15012005)
- 한국부동산원_부동산통계 조회 서비스(R-ONE) → 7번 임대료·공실률  (data 15134761)
- 국토교통부_(TAGO)_지하철정보 → 8번
- (필요 시) 국토부 POI → 9번 보완

## 보안 원칙

- **서버 전용 키(②·③, 카카오 REST)는 절대 프론트엔드 코드/번들에 넣지 않는다.**
  → Next.js **Route Handler(서버)**에서만 사용. 브라우저 → 우리 서버 → 공공 API.
- 공공/서울 API는 브라우저 **CORS 미허용**이 많아 서버 프록시가 필수.
- 카카오 **JavaScript 키만** 클라이언트에 노출하되, 콘솔에서 **도메인 제한** 설정.
- 실제 키 값은 `.env.local`(git 제외) 또는 배포 플랫폼 환경변수에만 저장.

## 환경변수 매핑

`.env.example` 참고. 실제 값은 `.env.local`에 복사해 채운다.
